# Wappers of [PyVista](https://pyvista.org/) for plotting stuff obtained from Jive simulations

An example can be found in (plot_rve_strain.py)[https://github.com/LATMororo/fe2/blob/main/examples/rve20/plot_rve_strain.py]. It is possible to use it
with (pyvistaqt)[https://github.com/pyvista/pyvistaqt] for iterative plots.
